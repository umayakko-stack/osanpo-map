# おさんぽマップ 🚶

GPSで散歩ルートを記録して、地図にマッピング。歩数・距離を計測し、
「フランスまで歩く」「南極まで歩く」などの目標への進捗を楽しむWEBアプリ。

## 機能

- **さんぽ** — ボタンひとつでGPS記録を開始/終了。ルートを地図にリアルタイム描画、時間・距離・歩数を表示
- **きろく** — 月別カレンダーで日々の記録を確認（日ごとの距離と体調絵文字を表示、‹›で月送り）。日付をタップするとその日の散歩だけに絞り込み。体調（😊良い・😐普通・😞悪い）を日付ごとに記録でき、過去の日付もカレンダーから選んで記録可能。散歩一覧はタップでルート再表示、🗑で削除
- **体調記録** — 散歩終了時のダイアログでもその日の体調をワンタップ記録。同じボタンをもう一度押すと取り消し。顔の色は 良い=緑 / 普通=黄 / 悪い=赤（カレンダー上も同色）
- **体重記録** — 「体調・体重」カードで日付ごとに体重(kg)を記録。カレンダーで過去の日付を選べば後から入力も可能。空欄で「記録」を押すと削除。2件以上たまると「体重のうつりかわり」折れ線グラフ（直近30件）を表示
- **もくひょう** — 目標地点（ソウル〜南極まで9か所）を選ぶと、累計距離から進捗％・残りkm・世界地図上の「いまここ」仮想地点を表示
- **バックアップ・復元** — 「せってい」から全データ（散歩・体調・体重・設定）をJSONファイルに保存／クリップボードにコピー。復元はファイル選択か貼り付けで、今の記録とマージされる（同じ散歩は重複しない）。機種変更やデータ消失に備えられる

## 技術メモ

- Leaflet + OpenStreetMap、データはlocalStorage保存（サーバー不要・完全ローカル）
- 歩数: 加速度センサー（DeviceMotion）で検出。センサーが使えない場合は 距離÷歩幅 で推定（歩幅は「せってい」で変更可）
- GPSノイズ対策: 精度50m超・移動3m未満・1秒で200m超の点は除外
- 記録中は画面スリープ防止（Wake Lock API）
- PWA対応（manifest.json）— スマホで「ホーム画面に追加」可能

## 動かし方

GPS（位置情報）は **https または localhost でのみ動作** します。file:// で直接開いても地図は出ますがGPSは使えません。

### PCで動作確認（デモモード）

```bash
python -m http.server 8090 --directory osanpo-map
```

→ http://localhost:8090/?demo を開くと、GPSなしで擬似散歩が動きます。

### スマホで使う

GitHub Pages / Netlify / Firebase Hosting などにフォルダごとアップロードして、
スマホのブラウザで開く → 「ホーム画面に追加」でアプリのように使えます。

- iPhoneの場合、散歩スタート時に「動作と方向」の許可ダイアログが出ます（歩数センサー用）。拒否しても距離からの推定歩数で動きます。
